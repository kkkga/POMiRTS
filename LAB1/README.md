## Цель работы

Получить навыки моделирования объекта управления в промышленных системах автоматического управления и создания функциональных блоков.

## Задание

Создать виртуальную систему управления двигателем постоянного тока, включающую модель объекта управления, ПИ-регулятор, сумматор и отрицательную обратную связь по скорости. Передаточная функция объекта:

```
W(s) = 1 / (ke * (Tm * s + 1))
```

## Функциональные блоки

| Блок | Назначение | Входы | Выходы |
|------|------------|-------|--------|
| `FB_Integrator` | Дискретный интегратор | `in` | `out`, `state` |
| `FB_Motor` | Модель двигателя (апериодическое звено, метод Эйлера) | `u` (напряжение, В) | `w` (рад/с), `phi` (рад) |
| `FB_Regulator` | ПИ-регулятор с ограничением выходного напряжения | `e` (рассогласование, рад/с) | `u` (В) |

Блок `FB_Integrator` используется внутри двух других: в `FB_Motor` он интегрирует ускорение и скорость, в `FB_Regulator` формирует интегральную составляющую.

## Основная программа

В программе `main` работают два канала с одним и тем же заданием:

- **с регулятором:** рассогласование `e = desired_w - fb_motor.w` подаётся на `fb_controller`, его выход идёт на `fb_motor`;
- **без регулятора:** напряжение задаётся напрямую, `fb_motor2.u = desired_w * ke`.

### Переменные

| Имя | Тип | Описание |
|-----|-----|----------|
| `fb_controller` | `FB_Regulator` | экземпляр ПИ-регулятора |
| `fb_motor` | `FB_Motor` | двигатель с регулятором |
| `fb_motor2` | `FB_Motor` | двигатель без регулятора |
| `speed` | `UINT` | уставка скорости, об/мин |
| `speed_in_rad` | `REAL` | уставка скорости, рад/с |
| `enable` | `USINT` | разрешение работы |
| `counter` | `UDINT` | счётчик циклов |

### Параметры

| Параметр | Значение |
|----------|----------|
| `dt` | 0.01 с |
| `ke` | 2.65 |
| `Tm` | 0.05 с |
| `k_p` | `ke * Tm / 0.02` |
| `k_i` | `ke / 0.02` |
| `max_abs_value` | 24 В |

## Результаты

Сигналы `speed`, `fb_motor.w` и `fb_motor2.w` записывались в Trace.

- Без регулятора скорость нарастает плавно по экспоненте и так же плавно спадает после снятия задания.
- С ПИ-регулятором скорость выходит на заданное значение заметно быстрее, перерегулирование не наблюдается.
- Быстрый разгон объясняется тем, что в начальный момент рассогласование велико, и регулятор подаёт на двигатель максимально допустимое напряжение.
- Установившееся значение в обоих каналах совпадает с уставкой.
